# Galumbra Supreme

A premium social media platform starter built with Next.js, TypeScript, and Tailwind CSS.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run start`

## Features

- premium dark-brand UI
- creator discovery cards
- social feed layout
- trending panel
- communities and live sections
- responsive design

## Getting started

```bash
npm install
npm run dev
```
